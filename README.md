# SCUTER manuscript

Primary Manubot repository for **SCUTER: Scientific Collaboration for User-directed, Traceable, Evidence-based Research**.

The manuscript source is maintained in `content/`. GitHub Actions builds the manuscript from the `main` branch and publishes generated outputs through the standard Manubot deployment workflow.

## Manuscript structure

- Abstract
- Introduction
- Methods
- Results
- Discussion

## Related resource

The reusable SCUTER implementation is maintained at <https://github.com/TaylorResearchLab/SCUTER>.
